# Ретрокосмос (Retro Cosmos)

Космический мод в эстетике американского ретрофутуризма 1950–60-х — атомный век, Googie,
pulp-фантастика и космическая гонка: серебристо-белые ракеты с вишнёво-красными стабилизаторами
и хромированным носом, бирюза и крем, звёзды и полосы, радиолампы и аналоговые вычислители,
Центр управления полётом и предстартовый отсчёт.

**Minecraft 1.21.11 · NeoForge 21.11.x · Java 21**

## Скачать

Готовый `.jar` — во вкладке [Releases](https://github.com/Replecant/anotherTest/releases/latest).
Каждый пуш в `main` автоматически собирается GitHub Actions, проходит smoke-тест на сервере
и публикуется новым релизом. Положите jar в папку `mods`.

## Этап 1 — Подготовка (текущая версия)

### Ресурсы
| Руда | Где | Даёт |
|---|---|---|
| Бокситовая руда (+ глубинносланцевая) | Y −16…112, часто | Необработанный алюминий |
| Титановая руда (+ глубинносланцевая) | Y −64…24, реже, нужна железная кирка | Необработанный титан |

Переплавка в печи/плавильне → слитки. Два слитка вертикально → пластина. Есть блоки металлов.

### Ретро-электроника
- **Радиолампа** — стеклянные панели + редстоун + медный слиток (×2)
- **Аналоговый вычислитель наведения** — 3 радиолампы, редстоун, компас, 3 титановые пластины

### Детали ракеты
- **Головной обтекатель** — алюминиевые пластины + редстоун-факел
- **Секция корпуса** — алюминиевые и титановые пластины + стеклянная панель (иллюминатор)
- **Стабилизатор** — алюминиевые и титановые пластины (×2)
- **Ракетный двигатель** — титановые пластины + огненный заряд + плавильная печь
- **Канистра ракетного топлива** — пустая канистра + 2 угля + порох + огненный порошок

### Ракета «Либерти-1» (Liberty I)
```
 [обтекатель]
[стаб.][вычислитель][стаб.]
[корпус][двигатель][корпус]
```
Ставится как конструкция высотой 3 блока: хромированный игольчатый нос, белый корпус с красной
полосой и иллюминатором, стреловидные красные стабилизаторы. ПКМ канистрой топлива — заправка
(4 канистры). ПКМ пустой рукой — **предстартовая проверка** от Центра управления: ракета на
стартовой площадке, баки полны, астронавт в полном скафандре. Пройдите её, чтобы получить
достижение «Есть отрыв!».

### Стартовый комплекс и снаряжение
- **Стартовая площадка** — жёлтый/чёрный бетон, титановые пластины, железные блоки (×4)
- **Скафандр**: шлем астронавта, скафандр, штаны, магнитные ботинки — из титановых пластин и белой
  шерсти. Белый скафандр с бирюзовым пультом на груди, хромированным поясом, красными перчатками и
  ботинками, нашивкой «звёзды и полосы» на плече и ранцем жизнеобеспечения на спине.

### Достижения
Отдельная ветка «Ретрокосмос: Подготовка» ведёт игрока от первой руды до готовности к старту:
«Крылатый металл», «Электронный мозг», «Зажигание», «Стартовый комплекс №1», «Либерти-1»,
«Есть отрыв!».

## Сборка вручную
```
./gradlew build          # jar в build/libs/
./gradlew runClient      # запустить игру с модом
```
Текстуры, модели, рецепты, лут, генерация мира и локализация генерируются скриптом
`python3 tools/gen_resources.py` (нужен Pillow).
