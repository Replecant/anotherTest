# Ретрокосмос (Retro Cosmos)

Космический мод в эстетике американского ретрофутуризма 1950–60-х — атомный век, Googie,
pulp-фантастика и космическая гонка: серебристо-белые ракеты с вишнёво-красными стабилизаторами
и хромированным носом, бирюза и крем, звёзды и полосы, радиолампы и аналоговые вычислители,
Центр управления полётом и предстартовый отсчёт.

**Minecraft 1.21.11 · NeoForge 21.11.x · Java 21**

## Скачать

Готовый `.jar` — во вкладке [Releases](https://github.com/Replecant/anotherTest/releases/latest).
Каждый пуш в `main` автоматически собирается GitHub Actions, проходит smoke-тест на сервере
и публикуется новым релизом. Положите jar в папку `mods`.

## Этап 1 — Подготовка (текущая версия)

### Ресурсы
| Руда | Где | Даёт |
|---|---|---|
| Бокситовая руда (+ глубинносланцевая) | Y −16…112, часто | Необработанный алюминий |
| Титановая руда (+ глубинносланцевая) | Y −64…24, реже, нужна железная кирка | Необработанный титан |
| Горючий сланец | Y 8…72, пластами | Сырьё для керосина RP-1 |

Переплавка в печи/плавильне → слитки. Два слитка вертикально → пластина. Есть блоки металлов.
**Аэросплав**: 2 алюминиевых + 1 титановый слиток → 3 смеси, смесь переплавляется в слиток аэросплава
(пластины — как обычно).

### Топливо (две компоненты)
- **Топливный завод** — горючий сланец + пустая канистра → **канистра керосина RP-1**. Работает на обычном
  печном топливе (уголь и т. п.), интерфейс как у печи.
- **Воздухоразделитель** — лёд (любой лёд или снежный блок как хладагент) + пустая канистра →
  **канистра жидкого кислорода (LOX)**.
- У ракеты два бака по 4 канистры: ПКМ канистрой RP-1 — топливо, канистрой LOX — окислитель.

### Ретро-электроника
- **Радиолампа** — стеклянные панели + редстоун + медный слиток (×2)
- **Жгут проводов** — медь, нить, редстоун (×2)
- **Аналоговый вычислитель наведения** — 3 радиолампы, 2 жгута, компас, 3 титановые пластины

### Детали ракеты
- **Двигатель** = камера сгорания (пластины аэросплава + огненный заряд) + турбонасос (аэросплав, медь, поршень,
  радиолампа) + сопло (титановые пластины), собираются вертикально с титановыми пластинами по бокам.
- **Абляционный теплозащитный экран** (кирпичи + титан) → **головной обтекатель** (алюминий, экран, редстоун-факел).
- **Секция корпуса** (алюминий, титан, стеклянная панель), **топливный бак** (алюминий + аэросплав),
  **стабилизатор** (×2).
- **Планер «Либерти-1»** = 4 секции корпуса + 2 бака + 2 стабилизатора + пластина аэросплава.
- **Ракета** = обтекатель + вычислитель + планер + жгут проводов + двигатель.

### Ракета «Либерти-1» (Liberty I)
```
 [обтекатель]
[вычислитель][планер][жгут]
 [двигатель]
```
Ставится как конструкция высотой 3 блока: хромированный игольчатый нос, белый корпус с красной
полосой и иллюминатором, стреловидные красные стабилизаторы. ПКМ пустой рукой — **предстартовая
проверка** от Центра управления: ракета на столе, площадка 3×3 собрана, башня обслуживания рядом,
баки RP-1 и LOX полны, астронавт в полном скафандре. Пройдите её, чтобы получить достижение
«Все системы — GO».

### Стартовый комплекс
- **Стартовая площадка** — 3 штуки за крафт (бетон, алюминий, титан, железо). Нужно **9 блоков квадратом 3×3**,
  ракета ставится на центральный. Площадка сама подбирает текстуры: центр с красной звездой, кромки и углы
  с жёлто-чёрной каймой.
- **Башня обслуживания** — красно-белая ферма (алюминий + железные решётки, ×4). Колонна **не ниже 3 блоков**
  вплотную к площадке (в кольце вокруг 3×3).
- **Пульт Центра управления** — Googie-тумба с зелёным ЭЛТ-экраном (алюминий, стекло, радиолампы,
  вычислитель наведения, титан, редстоун). ПКМ — экран управления пуском: состояние ракеты, площадки,
  башни, шкалы RP-1/LOX, лампы скафандра, табло GO/NO-GO и кнопки **ПРОВЕРКА / ОТСЧЁТ / СТОП**.
  Отсчёт T-10…0 с сообщениями и звуками; на нуле — «Есть отрыв!» (сам полёт — этап 2).

### Скафандр и кислород
- **Скафандр**: шлем астронавта, скафандр, штаны, магнитные ботинки — из титановых пластин и белой
  шерсти. Белый скафандр с бирюзовым пультом на груди, хромированным поясом, красными перчатками и
  ботинками, нашивкой «звёзды и полосы» на плече и ранцем жизнеобеспечения на спине.
- В нагруднике скафандра — **баллон на 300 секунд кислорода** (виден в подсказке предмета).
  Заправка: ПКМ канистрой жидкого кислорода в воздух (в надетом скафандре) или просто стоять рядом
  с пультом Центра управления / воздухоразделителем.
- В безвоздушной среде кислород расходуется; без полного скафандра или с пустым баллоном —
  удушье (урон как при утоплении) с предупреждениями на 60/30/10 с.
- **Панель телеметрии скафандра** (HUD в левом верхнем углу): шкала O2 с процентами и временем,
  лампы H/C/L/B целостности скафандра, давление/температура, мигающие предупреждения.
  Показывается в скафандре или при включённой симуляции.

### Команды (пока планет нет — для теста кислорода)
```
/retrocosmos oxygen on [игрок]        — включить симуляцию безвоздушной среды (уровень прав 2)
/retrocosmos oxygen off [игрок]       — выключить
/retrocosmos oxygen set <сек> [игрок] — выставить кислород в надетом скафандре (0…300)
/retrocosmos hud on|off               — показать/скрыть панель телеметрии
```
Настройки сохраняются на игрока и переживают смерть.

### Достижения
Отдельная ветка «Ретрокосмос: Подготовка» ведёт игрока от первой руды до старта:
«Чёрное золото», «Керосин атомной эры», «Холоднее космоса», «Сплав реактивной эры», «Зажигание»,
«Планер», «Девять стальных плит», «Стартовый комплекс №1», «Центр управления», «Все системы — GO»,
«Есть отрыв!», «Первый глоток консервированного воздуха».

## Сборка вручную
```
./gradlew build          # jar в build/libs/
./gradlew runClient      # запустить игру с модом
```
Текстуры, модели, рецепты, лут, генерация мира и локализация генерируются скриптом
`python3 tools/gen_resources.py` (нужен Pillow).
